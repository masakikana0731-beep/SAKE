# 🍶 酒ラベル帳

お酒のラベル（エチケット）をスマホのカメラで撮影し、**補正して記録・コレクション**できるWebアプリ（PWA）です。
ビルド不要。サーバーに置いてスマホで開き、「ホーム画面に追加」するとアプリのように使えます。

## 機能

| 段階 | 内容 |
|---|---|
| 📷 撮影 | 背面カメラでライブ撮影（ガイド枠・ライト対応）／カメラアプリ／写真ライブラリから選択 |
| ✂️ 補正 | 四隅ドラッグで**台形（射影）補正**、拡大ルーペ付き。**自動ホワイトバランス・コントラスト**、明るさ／コントラスト／彩度、シャープ、90°回転 |
| 💾 記録 | 端末内の IndexedDB に画像ごと保存（オフライン動作）。銘柄・酒蔵・種類・産地・精米歩合・度数・価格・日付・場所・料理・メモ |
| 🔍 OCR（β） | Tesseract.js でラベル文字を読み取り、候補をタップで入力（ネット接続時のみ） |
| ✨ 自動入力（AI不要） | ①内蔵の銘柄辞書（約150銘柄）から酒蔵・産地・カテゴリを補完 ②ラベル文字から精米歩合・度数・原料米・特定名称・産地・酒蔵をルールで抽出 ③Wikipedia を検索して概要から抽出（無料・登録不要）＋Google検索リンク。空欄だけを埋め、補完した欄は色で示す |
| 🎉 楽しむ | ★評価、味わいレーダーチャート（6軸）、飲み方・温度（燗など）、お気に入り、検索・並べ替え、シェア、都道府県めぐり、好みタイプ診断、今日の一本、バッジ13種 |
| 🗂 データ | JSON でバックアップ／復元 |

## 動かし方

```bash
# ローカル確認（PC）
npx http-server -p 8080 .   # または python3 -m http.server 8080
```

スマホのカメラは **HTTPS 必須** です。手軽なのは GitHub Pages：
リポジトリの Settings → Pages → Branch を選んで公開 → `https://<user>.github.io/<repo>/` をスマホで開く。

## 構成

```
index.html          画面
styles.css          スタイル
js/app.js           画面遷移・フォーム・一覧・統計
js/correct.js       画像補正（射影変換・自動レベル・シャープ等）
js/camera.js        カメラ制御
js/db.js            IndexedDB
js/data.js          都道府県・種類・バッジ定義
sw.js               オフライン用 Service Worker
```

## 注意・今後の候補

- データは**その端末のブラウザ内のみ**に保存されます。機種変更前はバックアップを。
- OCR は縦書き・筆文字・装飾文字の多い酒ラベルでは精度が低い場合があります。
- 今後：ラベル四隅の自動検出、クラウド同期・複数端末共有、友達と飲み比べ共有 など。
